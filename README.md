Aplicativo móvel desenvolvido em React Native com Expo para agendamento de serviços em barbearias.

Funcionalidades
Seleção de barbeiro profissional
Calendário para escolha de data
Serviços com preços
Horários de 15 em 15 minutos
Bloqueio de horários já ocupados
Lista de agendamentos com cancelamento
Tela de perfil do usuário
Modais de confirmação e sucesso
Tecnologias
React Native
JavaScript / JSX
Expo Snack (snack.expo.dev)
